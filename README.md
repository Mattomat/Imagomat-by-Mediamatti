# Imagomat by Mediamatti

Lokale Desktop-App für KI-gestütztes Culling, Personen-Zuordnung und individuelle
Bildentwicklung im persönlichen Stil. Ausgabe als RAW + XMP für Lightroom Classic.

**Status:** Phase 0 (Recherche und Machbarkeit). Siehe
[docs/phase0/Machbarkeitsbericht.md](docs/phase0/Machbarkeitsbericht.md).

Grundsätze: Alles läuft lokal, RAW-Originale bleiben unverändert, alle Bearbeitungen
sind nicht-destruktiv (XMP).
